公开信号会把自愿披露挤出去

Chen & Jin, NBER WP 35625，2026年8月 · 精读 kyle-2026-08-19-p4 · Kyle · 2026-08-20 按全文讲解标准重写

监管多放一个和公司私有信息相关的公开指标（评级、一致预期、股价），本意是让外面的人多知道一点。这篇说：如果看的人有点天真，这个指标会改写他们对「公司为什么不说话」的解读。指标越好，沉默越被当成「大概还行」，中间类型更敢藏。加总信息量可以比「没有这个公开指标」更差。

下面不是日报短评。先把经典 unraveling 的推导走完，再把他们加的 public signal 和 partial naivete 嵌进去，把 equilibrium 门槛、比较静态、实验在测什么、和你跟 Jeff 做的空公告 / 问询函怎么对上，一步步写清楚。

1. 先把经典 unraveling 推导一遍

Grossman (1981)、Milgrom (1981) 的可验证披露。先把这个物体钉死，后面所有「嵌套解包」才有落点。

1.1 设定

  • 发送方（公司）知道一个数字 θ，落在闭区间 [θL, θH] 上，分布 F 连续、密度 f > 0。θ 是质量、盈余、考试分数。
  • 发送方有两个动作：disclose（交出真值 θ）或 silence（什么都不交）。不能撒谎。这叫 verifiable disclosure，不是 cheap talk。
  • 接收方（投资者）完全贝叶斯。看见披露就信那个数；看见沉默，按「哪些类型会选择沉默」来算条件期望。
  • 发送方的收益就是接收方的猜测 ĝ。他只在乎水平，不在乎方差，也没有第二期会被打脸。

时间线：Nature 抽出 θ → 发送方看见 θ，决定说还是藏 → 接收方给出 ĝ。

人话：成绩单你能交也能藏。交了就按真分数打。藏了，别人按「会藏的那些人」的平均分打。你希望别人打得越高越好。

1.2 Equilibrium：门槛策略

猜一个门槛 t。类型 θ ≥ t 的选择披露，θ < t 的选择沉默。接收方猜对了这个策略，所以：

看见 θ → ĝ = θ
看见沉默 → ĝND = E[θ | θ < t]

人话：说了就按真值；不说，就按隐瞒池的均值开价。

发送方比的是「说出来拿 θ」还是「闭嘴拿 ĝND」。对门槛上的人，两边打平：

t = E[θ | θ < t]

人话：刚好在门槛上的类型，交成绩单和藏成绩单，拿到的猜测一样。

1.3 为什么唯一解是 t = θL

连续分布下，只要 t > θL，隐瞒池是 [θL, t) 这一截，它的均值严格小于右端点：

E[θ | θ < t] < t  （对所有 t > θL）

人话：一堆比 t 小的数，平均不可能等于 t。所以 t = E[θ | θ < t] 在 t > θL 处无解。

只剩下 t = θL：隐瞒池退化成最差的那一点，沉默 = 最差。除了最差，人人披露。这就是完全 unraveling。

1.4 均匀分布走一遍算术

设 θ ~ Uniform[θL, θH]。条件期望是区间中点：

E[θ | θ < t] = (θL + t) / 2

代入无差异条件：

t = (θL + t) / 2  ⇒  t = θL

人话：就算你先猜一个中间门槛，算完隐瞒池均值一定比门槛低，门槛上的人宁可说。门槛被往下推，一直推到左端点。

倒着讲同一件事：最好的类型说了一定加分，所以一定说。接收方看见沉默，就知道「不是最好的」。于是次好的也被逼着说。一层层剥下去，只剩最差还在藏。

1.5 现实里解包为什么推不完

公司经常藏中间类型。文献常用三刀砍开：

  • 发送方不一定知情（Dye 1985）。沉默可能是「没看见」，不只是「看见了很烂」。隐瞒池被「不知情」稀释，门槛可以停在中间。
  • 披露有成本（Jovanovic 1982）。中间类型交成绩单的成本盖过加分。
  • 接收方不是完全理性，解包推不完。Jin, Luca, Martin (AEJ: Micro 2021) 的实验室就是 Ginger Jin 自己做的：发送方会藏不太好的消息，一部分接收方不会把沉默解到最差。

Chen–Jin 走第三刀，再加一样东西：市场上已经有一个和私有状态相关的公共信号。天真接收方会把沉默往这个信号上靠。

这不是 Grossman–Stiglitz 那种「公共信息挤出私人挖信息」。GS 挤的是 information acquisition：价格已经反映了很多，谁还花钱去挖。这篇挤的是 voluntary disclosure：公开指标已经把沉默读宽了，谁还交成绩单。

2. 他们加了什么：public signal + partial naivete

作者原话能核到 作者主页：We study how voluntary disclosure responds to a correlated public signal when receivers are partially naive. We develop a framework in which the public signal shifts naive receivers' interpretation of silence.

2.1 谁、看见什么、图什么

  • 发送方看见私有状态 θa。只能如实披露或沉默。和 Dye 不同：这里发送方一定知情，藏是策略，不是运气。
  • 公共信号 θb：所有人都能看见，和 θa 正相关，相关系数记作 ρ。例子：分析师一致预期、另一家评级、GPA、旧财报、股价。
  • 接收方部分天真。看见披露就按真值信。看见沉默，不会只做理性的「隐瞒池均值」，还会把公共信号掺进去。
  • 发送方目标：让接收方的猜测尽量高（股价、录取概率）。

时间线

  1. Nature 抽出 (θa, θb)，相关为 ρ。
  2. 发送方看见 θa（通常也看见 θb），决定 disclose 或 silence。
  3. 接收方看见 θb，以及「说了的真值」或「沉默」，给出猜测 ĝ。
  4. 发送方拿到 ĝ。

2.2 部分天真：教学用的线性混合

文献里「不会倒推选择」的标准物体是 Eyster–Rabin 的 cursed equilibrium：接收方看见沉默，没有充分反推「哪些类型才会藏」。Jin–Luca–Martin 的实验室也是这一类。

标准模型推导 下面这个 λ 是教学用的，不要当成他们论文里的符号。它把「公共信号改写沉默解读」写成能算的式子：

ĝND(θb) = (1 − λ) · E[θa | ND, θb] + λ · m(θb)

人话：沉默后的猜测 = 一边听隐瞒池均值，一边听公开指标。λ 是「有多听公开指标」。λ = 0 退回完全贝叶斯；λ > 0 把沉默往 θb 上拉。m(θb) 是接收方从公开指标读出的「大概多少」，最简单就取 m(θb) = θb。

作者说 public signal shifts naive receivers' interpretation of silence。上面这个式子就是这句话的一个可操作版本：θb 进了 ĝND，而且是通过天真权重 λ 进去的，不是只通过理性的条件期望进去的。

2.3 为什么必须有 naivete，否则故事反着来

这是整篇最容易读反的一步。完全理性（λ = 0）时：

ĝND(θb) = E[θa | θa < t(θb), θb]

人话：理性人已经知道「好公司更可能说」。公共信号越好，越说明「还在藏的人更差」。隐瞒池被读得更窄，解包压力更大，不是更小。

所以：好的公共信号挤出披露，是天真接收方现象。 没有 λ > 0 这一刀，favorable θb 会加强 adverse selection 推断，发送方更不敢藏。作者把机制钉在 partial naivete 上，不是随便加的行为假设。

3. Equilibrium：门槛怎么解出来

作者原话能核到 他们推出一个 closed-form disclosure threshold，嵌套经典 unraveling。

标准模型推导 发送方披露当且仅当交出来更好：

disclose  ⇔  θa ≥ ĝND(θb)

人话：真值已经比「闭嘴能拿到的猜测」高，就说；否则藏。

接收方猜对门槛，所以 ĝND 本身依赖于「哪些人在藏」。门槛 t(θb) 是一个不动点：

t(θb) = (1 − λ) · E[θa | θa < t(θb), θb] + λ · m(θb)

人话：门槛上的人刚好打平。右边第一项是「藏的那些人有多差」，第二项是公开指标把沉默抬了多少。两边要自洽：你用来算隐瞒池的门槛，必须等于算完之后的猜测。

3.1 嵌套解包

令 λ = 0，且先关掉 θb（或者 ρ = 0，θb 不提供关于 θa 的信息）。式子退回

t = E[θa | θa < t]

第 1 节已经证明，连续分布下唯一解是 t = θL。这就是作者说的 nesting classical unraveling：天真权重为零时，回到「只藏最差」。

3.2 均匀分布的教学例子（不是他们的闭式）

先做一个能手算的特例，只为看清门槛怎么被 θb 抬起来。设 θa ~ U[0, 1]，先忽略「θb 还会改理性项」这一层，令 E[θa | θa < t] = t/2，m(θb) = θb。则

t = (1 − λ) · (t / 2) + λ · θb

移项：

t − (1 − λ)t / 2 = λ θb  ⇒  t · (1 + λ) / 2 = λ θb
t(θb) = 2λ / (1 + λ) · θb

人话：λ = 0 时 t = 0，完全解包。λ 变大，门槛按 θb 的某个分数往上抬。θb 越好，藏的区间越大。这是教学闭式，用来看方向；不是他们论文里的那个 closed-form。

更完整的理性项 E[θa | θa < t, θb] 会随 ρ 动：ρ 越大，给定 θb 之后，θa 的条件分布越窄。λ = 0 时这一项会让好的 θb 把隐瞒池读得更差（解包更狠）；λ > 0 时第二项 λ m(θb) 往相反方向拉。挤出能不能出现，取决于天真项是否压过理性的 adverse selection 项。作者能写出闭式，说明他们选了一组能解到底的分布和信息结构。具体函数等 PDF。

4. 比较静态

下面五条，方向来自作者能核到的原话；中间的「为什么」用第 3 节的门槛走。

4.1 好信号挤出，坏信号挤入

作者原话能核到 A favorable public signal can crowd out disclosure.

门槛 t(θb) 随 θb 上升：公开指标越好，沉默被读得越宽，中间类型更愿意藏。披露集合 [t, θH] 变短。反过来，θb 很难看时，沉默被读窄，更多人被迫说——crowd-in。

实验室里他们变动「公共信号有多有利」，对应的就是这条对 θb 的比较静态。

4.2 相关越强，这条斜率越陡

作者原话能核到 Disclosure falls as the public signal becomes more favorable, and the decline is amplified by stronger correlation.

人话：同样是「公开指标变好一截」，ρ 更大时，天真接收方更把 θb 当成 θa 的替身，λ m(θb) 这一项更沉，门槛抬得更狠，披露掉得更多。

4.3 沉默后的猜测朝公共信号偏

作者原话能核到 Receiver guesses upon non-disclosure rise correspondingly, departing from the rational benchmark toward the public signal.

理性基准是 E[θa | ND, θb]。观测到的猜测往 m(θb) 挪。这是在直接测 λ > 0，不是只测发送方少说了。少说可能有别的原因（成本、 Dye 式不知情）；猜测朝 θb 偏，才是「沉默被公开指标读宽」这条机制。

4.4 策略性沉默可以反过来挤掉公共信号自己

作者原话能核到 Strategic silence can thus crowd out the public signal itself, and transparency can be lower with it than without.

把三个世界的信息量并排看：

  • 没有公共信号。 接收方只靠自愿披露。若 λ 不太大，解包推得比较深，很多人交 θa。
  • 有公共信号 + 理性接收方。 θb 自己带一点关于 θa 的信息；沉默的推断也更狠。信息量通常不会比「没有」更差。
  • 有公共信号 + 天真接收方。 θb 加了一点信息，但把一大截自愿披露挤掉了。接收方在沉默时拿到的是「往 θb 靠的混合」，而不是 θa。少掉的那截自愿披露，可能比 θb 本身带来的还多。

「挤掉公共信号自己」是说：你本来想靠 θb 多告诉接收方一点，但发送方因此改了策略，接收方最终看到的有效信息，比你放 θb 之前还少。θb 的增量被策略性沉默对冲掉了。

4.5 对 ρ 不是单调的，中间最狠

作者原话能核到 The effect is non-monotonic in the correlation: strongest when the signal is informative enough to anchor beliefs but too noisy to substitute for disclosure.

两个极限：

  • ρ ≈ 0。θb 和私有状态几乎无关。天真接收方就算想锚定，也锚在一个不相干的数上；发送方知道接收方这个锚不准，挤出有限。
  • ρ → 1。θb 几乎把 θa 说穿。藏不住：接收方即使用 θb 替代披露，误差也接近零。人人说或人人都被看穿，信息损失回来。

中间：信号够强，能改「沉默大概还行」的信念；又不够准，替代不了开口。这是最适合藏的区间。政策上最危险的，往往不是「完全没公开信息」或「公开信息几乎充分」，而是「放了一个吵但不准的相关指标」。

5. 假设为什么这么设，放松会怎样

逐条。哪一条断了，故事就断。

5.1 可验证，不能撒谎

发送方要么交真分数，要么闭嘴。A 股空公告、模板回复（「以公告为准」「暂无」「感谢关注」）更接近 cheap talk，或「说了等于没说」，不是这篇的「交成绩单」。对空公告要改一刀：把 disclosure 定义成「给出可核验的数字或事实」，空话算沉默。不改这一刀，模型对不上制度。

5.2 发送方一定知情

不是 Dye。沉默没有「没看见」这个开脱。A 股异动公告是强制开口，公司一定知道自己有没有应披事项——更接近这篇，而不是 Dye。问询函也是：监管已经认定你知情，逼你说。

如果改成 Dye（有概率没信息），沉默被进一步稀释，门槛更容易停在中间。公共信号的挤出还在，但会和「也许真不知道」叠在一起，identification 更脏。

5.3 收益只在乎猜测的水平

没有「说错了会被打脸」的第二期，也没有方差厌恶。你跟 Jeff 做的「空公告 → 45 天内打脸 → 再空公告」是这篇没有的动态。要把接收方的 λ 写成「上一次打脸」的函数：打脸之后，散户不再把沉默往好信号上靠，λ 下降，解包压力回来。这是你的增量，不是他们的命题。

5.4 接收方部分天真

第 2.3 节写过：没有这一刀，好信号会加强解包，挤出不会出现。实验室里他们用「猜测朝 θb 偏、偏离理性基准」来抓这个假设，不是只抓披露率。

如果接收方是机构、做市商、能倒推选择的人，这篇的符号可能翻掉。A 股里要把「谁在读公告」分开：散户更接近 naive，买方研究更接近贝叶斯。混合接收方下，发送方面对的是加权后的 ĝND。

5.5 ρ 在中间，不是 0 也不是 1

第 4.5 节。政策含义钉在这里：监管若只能强制「相关的公开指标」、强制不了私有状态本身，有可能把透明度弄得更差。作者写的是 cautionary message，不是「永远不要公开信号」。

5.6 没有市场、没有价格冲击

这不是 Kyle 模型。没有做市商、没有订单流、没有 adverse selection 进价差。θb 如果是股价本身，在微观结构里既是信号也是均衡结果，这篇没有处理这个固定点。你要是把涨停当成 θb，要想清楚：涨停是交易出来的，不是实验里外生抽的。

6. 实验：在测什么、怕什么、主结果怎么读

作者原话能核到 实验室变动私有状态和公共信号的相关系数。披露随公共信号变好而下降，相关越强降得越多；不披露时接收方的猜测朝公共信号抬，偏离理性基准。

人数、轮次、处理名称、估计的 λ，原文没打开，不写。

6.1 在比谁

不是「公开信息多了价格更有效」。是两件事同时成立：

  1. 发送方：公共信号越有利，越不披露；这条斜率在 ρ 更大时更陡。
  2. 接收方：沉默之后的猜测，不跟着理性隐瞒池走，跟着 θb 走。

两件事缺一不可。只有 (1)，可能是成本、疲劳、没看懂规则。加上 (2)，才是「沉默被公开指标读宽」。

6.2 identification

实验室随机给 (θb, ρ)。这不是公司层面的 DID，也没有 instrument。外生性来自实验者抽签。理性基准可以按规则和分布算出来，拿观测猜测去减，就是「朝公共信号偏了多少」。

人话：他们能指着一张图说「同一群人，只是公开指标变好了 / 相关变强了，披露掉了，猜测抬了」。这是实验 identification 的全部。

6.3 怕什么

  • experimenter demand：被试猜到你想看「有公开信号就少说」，按剧本演。
  • 没懂 verifiability：以为可以报一个假数字。规则一旦被理解成 cheap talk，整篇模型换了。
  • 跨轮学习：同一对作者的 SAT 篇（NBER w33660）发现被试对「学校怎么解读不交分数」学得不完全。这篇如果也是多轮，要把「一开始就偏」和「学完还偏」分开。那是相关论文的结果，不是这篇已经核到的数字。
  • measurement：披露率好测。理性基准要按他们写的分布和策略算，算错了「偏离」就是假的。原文没打开，这里不重算。

6.4 主结果怎么读（只有方向）

  • 横轴：公共信号有多有利。纵轴：披露率。作者说这条线往下；ρ 更大的那组更陡。
  • 横轴：同样。纵轴：沉默后的猜测。作者说往上，方向朝 θb，不是朝理性隐瞒池均值。
  • 信息量：有公共信号的世界，可以低于没有的世界。这是加总命题，不是单看披露率。

具体点估计等 PDF。不要把日报里任何未复核的实验数字当结果。

7. 对上董杰的空公告、涨停、问询函

这篇不是 A 股制度论文。机制和「空公告当强制 cheap talk」是同一类物体：公司必须发声（异动公告、问询函回复），内容却可以是空的。把空话当成沉默，把市场上已经有的东西当成 θb。

7.1 映射

  • θa：公司私有的、可核验的那件事（有没有应披事项、业绩数字、合同）。
  • disclosure：公告里出现新的数字或事实。
  • silence：「无应披未披」「以公告为准」「暂无」「请查阅公告」。发了公告但没有可核验内容。
  • θb：已经涨停、已经放量、龙虎榜、北向、分析师一致预期、同业公告、行业景气新闻；以及你样本里「45 天内打脸」的事后公共信号。
  • ρ：这类公开信号平时能预测多大的后续基本面。涨停很吵，和「到底有没有应披事项」只是中等相关——正好落在作者说的危险区间。

7.2 这篇直接给的预测

  • 异动当天已经涨停、情绪面很好时，空公告应该更多，不是更少。和「公司没话说所以才空」的朴素故事反着：没话说加上市场已经很好，更空。
  • 相关中等时挤出最狠。涨停是很吵但不准的 θb。
  • 问询函是监管强制开口。若市场已经有很强的公开叙事，函件回复更容易滑向模板。Hudongyi 那组「以公告为准、暂无、感谢关注」是同一方向。论文 (2) 先挂着等论文 (6)，这篇给理论借口：模板回复是被公共信号读宽之后的最优沉默。

7.3 这篇解释不了、你必须自己加的

  • 打脸后的声誉。 模型是一期。你关心的是「被证明说空话之后，下一次还空不清空」。λ(打脸) 下降，解包回来。这是增量。
  • 空话不是可验证披露。 他们要么交真分数要么闭嘴。你的 DV 必须是「有没有可核验数字 / 新事实」，不要用「发没发公告」——公告是强制的。
  • 价格本身既是结果也是信号。 涨停既是 θb，也是接收方猜测的市场版。这篇没有订单簿。

7.4 假如和 Jeff 做：测什么、怕什么

先讲在测什么：不是「公开信息多了价格更有效」，是「公开信号越好，公司越不提供可核验的自愿信息」。

  • DV：异动公告 / 预告 / 问询函回复里，有没有新的数字或事实。空模板 = 沉默。
  • 核心自变量：公告前已实现的公共信号——涨停幅度、超预期程度、分析师预测相对最后一次财报的位置。预测：信号越有利，沉默越多。
  • ρ 的代理：这类公开信号平时能预测多大的后续基本面。预测：中等预测力的信号，挤出最大；几乎完美的信号（业绩已预告），挤出反而小。
  • 怕什么（selection / omitted）：好信号的日子公司本来就没事可说。需要一个「信号好、但不是公司自己放出」的变异——行业冲击、指数涨停、同业公告。这才接近他们实验室里外生变动 θb。
  • 不要用 CAR 当主 DV。 问询函那轮：CAR[0,1] 8.17% → 3.72%（t = −1.47），同日超额 7.10% → 3.33%（t = −1.90）。方向还行，不显著；而且 8% 很大一块就是涨停本身，不是 cheap talk 有没有被信。这篇的被解释变量是「说还是藏」。

8. 文献位置

  • Unraveling：Grossman (1981), Milgrom (1981)。完全知情、可验证、理性接收方 → 只藏最差。
  • 砍开解包：Dye (1985) 不知情；Jovanovic (1982) 披露成本。
  • 天真接收方 + 披露实验室：Jin, Luca, Martin (AEJ: Micro 2021)。Ginger 自己的前一篇实验：解包推不完。
  • Cursed / 不会倒推选择：Eyster–Rabin。教学用的 λ 和这个是一类物体。
  • 同一对作者的招生版：Chen–Jin, NBER w33660《Voluntary Report of Standardized Test Scores》。可选 SAT：学校把「不交」解读得越宽，学生越不交。那是这篇机制的学校政策现场。A 股空公告是上市公司版。
  • 不是：Grossman–Stiglitz（挤的是挖信息，不是开口）；也不是 Kyle（没有价格冲击）。
顶刊作者：Ginger Zhe Jin — QJE 2003「The Effect of Information on Product Quality: Evidence from Restaurant Hygiene Grade Cards」（with Leslie）。披露实验另有 AEJ: Micro 2021，不在你定的顶刊清单里，只作机制背景。
